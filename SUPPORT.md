# Support

Use [GitHub Issues](https://github.com/jdshfhds/northcinder/issues) for reproducible bugs, documentation
problems, and focused feature requests.

Before opening an issue:

1. Check [`README.md`](./README.md) and search existing issues.
2. Reproduce the problem against the current `main` branch.
3. Include the affected package, Node and pnpm versions, exact command, expected result, and a short
   sanitized error excerpt.

Do not post credentials, bearer tokens, browser profiles, delegated payment tokens, confirmation
codes, approval URLs, private mail, purchase records, or audit logs. Vulnerabilities belong in the
private route described in [`SECURITY.md`](./SECURITY.md).

Issues are an optional source-maintenance channel, not a runtime dependency. NorthCinder has no
repository-owner-operated service or status page, and installed copies continue to run if the
repository owner is unavailable.
